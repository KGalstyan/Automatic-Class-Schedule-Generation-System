# Automatic-Class-Schedule-Generation-System

Automated weekly class-timetable generator built with Python & PyQt — uses a backtracking/greedy algorithm to schedule teachers, student groups, and classrooms with automatic conflict detection.

## Features
- CRUD management for teachers, subjects, student groups, and classrooms
- Automatic schedule generation using a greedy/backtracking algorithm
- Real-time conflict detection (teacher, group, and room double-booking)
- Manual schedule editing
- Filter and view schedules by group, teacher, or classroom
- Export to CSV / JSON
- SQLite-based persistent storage
